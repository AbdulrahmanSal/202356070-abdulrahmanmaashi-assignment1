# Abdulrahman Saleh Maashi — Personal Portfolio

## Project Description

This project is a responsive personal portfolio website created for Assignment 1: Foundation & AI Integration. It introduces me, presents two academic projects, and provides a contact form. The website was built to practice foundational HTML, CSS, and JavaScript skills while learning how to use AI tools responsibly during development.

## Features

- About Me section with a short personal introduction
- Projects section featuring the Hotel Reservation System, House Price Prediction Model, and Digital Queue Management System
- Contact form with name, email, and message fields
- Dark and light theme toggle, remembered between visits
- Greeting message that changes with the time of day
- Click-to-enlarge lightbox for project screenshots
- Responsive layout for desktop, tablet, and mobile screens
- Accessible labels, alternative image text, and semantic HTML elements
- Accessible GitHub footer link announces that it opens in a new tab, while `target="_blank"` and `rel="noopener noreferrer"` provide safer external linking

## Technologies Used

- HTML5 for the page structure and content
- CSS3, Grid, and Flexbox for styling and responsive layout
- JavaScript for the theme toggle, greeting, nav highlighting, and form validation
- Git and GitHub for version control and project hosting
- Claude (Anthropic) for development assistance, troubleshooting, and documentation support

## Running the Website Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation, package manager, or backend server is required.
